# UPS

Локальный монитор питания для ИБП с протоколом Megatec / Mega(USB). Программа сделана взамен UPSmart: та вылетала и не устраивала своим функционалом. UPS работает только на этом компьютере: окно, трей и уведомления остаются у вас, сервер слушает `127.0.0.1`.

Версия пакета: **1.1.0**.

## Что умеет

- Опрашивает ИБП и показывает вход, выход, нагрузку, частоту, температуру, заряд и расчётную автономию.
- Рисует схему тракта: сеть, байпас, AVR, батарея, инвертор.
- Ведёт живой график, журнал событий и суточные HTML-отчёты.
- Считает энергию по выборкам нагрузки.
- Шлёт уведомления Windows и в Telegram. В боте есть состояние, журнал, отчёт дня, сводка, скриншот окна и кнопки питания ПК.
- Может выключить компьютер, если сеть пропала и ИБП ушёл на батарею.
- Сворачивается в трей и умеет стартовать вместе с Windows.

## Требования

- Windows
- Python 3 в `PATH` (лаунчер `py`)
- ИБП с протоколом Megatec по USB HID (Mega USB) или по COM-порту

## Установка

```bat
py -3 -m pip install -r requirements.txt
```

Зависимости: `pyserial`, `pywebview`, `pystray`, `pillow`.

## Запуск

Обычный запуск без консоли:

```bat
start.bat
```

Если предыдущая копия ещё слушает порт `8765`, `start.bat` сначала просит её закрыться.

Запуск от администратора (нужен для выключения и гибернации ПК):

```bat
start-admin.bat
```

Из командной строки:

```bat
py -3 app.py
py -3 app.py --demo
py -3 app.py --browser
py -3 app.py --port 8765
```

`--demo` показывает пример без устройства. `--browser` открывает интерфейс в браузере вместо своего окна.

## Подключение

При старте программа ищет USB HID-устройство Mega(USB) и опрашивает его командой `Q1`. Если ИБП сидит на последовательном кабеле, укажите COM-порт в настройках или выберите его в поиске портов.

Пока открыт UPSmart, устройство может быть занято. Закройте его и нажмите «Искать снова».

## Настройки

Шестерёнка в шапке окна:

- интервал опроса, мощность ИБП (кВА), пороги напряжения сети;
- калибровка батарей: число банок, параллельные группы, ёмкость, пороги напряжения;
- звук при пропадании сети;
- автозапуск (ярлык `UPS.lnk` в папке автозагрузки Windows);
- журнал и папка отчётов;
- выключение ПК через заданное число секунд после перехода на батарею.

Настройки и история лежат в папке `data/` (она не попадает в git): `settings.json` и `history.sqlite`.

## Telegram

Вкладка «Телеграм»: вставьте токен бота от [@BotFather](https://t.me/BotFather) и привяжите чат кодом. У чата может быть полный доступ, роль администратора или гостя — у гостя набор событий и кнопок задаётся отдельно.

Команды питания ПК подтверждаются в чате. Выключение и гибернация срабатывают, если программа запущена с правами, которых хватает Windows на эти действия.
